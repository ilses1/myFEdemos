# ALIGNMENT_ui_fund_search_service

## UI 视觉细节分析

- **搜索框样式**:
  - 边框: 蓝色 (#5b7edb 左右)，圆角约 4px。
  - 左侧图标: `SearchOutlined`，蓝色。
  - 右侧图标: `DoubleRightOutlined`，用于折叠。
  - 占位符: “搜索基金”（根据用户要求去掉了“/经理”）。
- **折叠状态**:
  - 呈现为一个圆形的搜索图标按钮。
  - 蓝色边框，白色背景。
- **结果列表 (上方弹出)**:
  - 位置: 搜索框正上方。
  - 样式: 白色背景，带阴影的卡片。
  - 列表项结构: `[REITs 标签] [代码] [名称]`。
  - REITs 标签: 红色边框，红色文字，极小字号。
  - 代码: 蓝色文字。
  - 名称: 深色文字。

## 交互逻辑确认

- **初始状态**: 展开状态，显示“搜索基金”占位符。
- **折叠操作**: 点击右侧 `>>` 图标，搜索框向右收缩变为圆形搜索图标。
- **展开操作**: 点击折叠后的圆形图标，展开为搜索框并自动聚焦。
- **聚焦操作**:
  - 占位符消失。
  - 显示光标。
  - 上方显示“历史搜索记录”（若输入框为空）。
- **搜索操作**:
  - 输入内容时实时过滤数据。
  - 上方显示匹配结果。
  - 点击结果项（本阶段暂不处理跳转，仅展示 UI）。

## 疑问澄清

- Q: 搜索历史数据来源？ A: 暂定为 Mock 静态数据。
- Q: REITs 代码格式？ A: 6 位数字，如 508031。
